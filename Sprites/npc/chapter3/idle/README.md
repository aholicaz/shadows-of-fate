# NPC บท 3 — Idle หน้าตรง

NPC ทั้ง 7 คนหันหน้าตรงเข้ากล้อง พร้อมเสาวาปแห่งรากอีก 1 ชุด พื้น PNG โปร่งใสจริงทุกชุด

รายชื่อ: njorda = ผู้อาวุโสญอร์ดา, eskil = นักบันทึกเอสกิล, sifa = แม่ค้าซิฟา, galla = ช่างรากไม้กัลลา, leif = หมอสมุนไพรลีฟ, arvid = ทหารยามอาร์วิด, frida = เด็กหญิงฟรีดา, root_warp = เสาวาปแห่งราก

- `*_idle.png`: ชีท 3 คอลัมน์ × 2 แถว ขนาด 1536×1024 พิกเซล
- `*_standing.png`: ภาพยืนเดี่ยว 512×512 สำหรับนำไปทำท่าอื่น
- โฟลเดอร์ตามชื่อ: PNG แยก 6 เฟรม ขนาด 512×512
- `*_idle.tres`: SpriteFrames พร้อมแอนิเมชันชื่อ `Idle` แบบวนซ้ำ 5 FPS และยืดเวลาท่าพัก

ใช้ใน Godot: ลากไฟล์ .tres ลงช่อง Sprite Frames ของ AnimatedSprite2D แล้วเลือกเล่น Idle จุดอ้างอิงเท้าในเฟรมประมาณ (256,472); ถ้าวาง origin ที่เท้า ใช้ offset (0,-216) เมื่อ centered=true ปรับขนาดเด็กให้เล็กกว่าผู้ใหญ่เมื่อวางในฉาก

เป็นชุด Idle ทดลอง 6 เฟรมที่สร้างด้วย ImageGen มีหายใจ/กะพริบตาและรายละเอียดผ้าเปลี่ยนเล็กน้อยระหว่างเฟรม จัดสเกลร่วมและแนวเท้าให้แล้ว ติดตั้งใน scenes/maps/vanir_town.tscn แล้ว พร้อมเล่น Idle อัตโนมัติ

ต้นฉบับเต็มและ prompt ที่ใช้ built-in ImageGen อยู่ใน `output/npc_chapter3/originals` และ `output/npc_chapter3/prompts.json` ตัวอย่างเคลื่อนไหว: `output/npc_chapter3/idle_preview.webp`
