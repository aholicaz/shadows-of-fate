# รูปลักษณ์ไอคอนสกิลโจมตี

ใช้ภาพที่ผู้ใช้กำหนดเป็นต้นแบบหลัก: `Sprites/Magnum Break.png`, `Sprites/skill_slash.png`, `Sprites/Skill_bash.png`.

- กรอบวงกลมโลหะสีเทาอมบรอนซ์ ขอบลาดมีไฮไลต์บาง และวงในสีดำ
- ภายในสีแดงเข้มถึงดำ แสงโจมตีส้มทองและแกนแสงขาวร้อน ประกายแดง
- ลายเส้นภาพวาดแฟนตาซีแบบอนิเมะ คมชัด รูปทรงหลักอ่านออกเมื่อย่อเหลือ 48–64 px
- ไม่มีชื่อสกิล ตัวอักษร หรือตัวเลขในภาพ พื้นนอกกรอบโปร่งใสจริง
- รูปกลางสื่อพฤติกรรมสกิลและต้องแยกจากสกิลอื่นได้
- ไฟล์ใช้ในเกม PNG RGBA 256×256; เก็บต้นฉบับขนาดใหญ่ใน output

Rending Wave: อ้างอิงเอฟเฟกต์จริงจาก `Sprites/effects/rending_wave_gold.png` ที่ผูกผ่าน `data/sprites/fx_rending_wave.tres` เป็นลิ่มคลื่นเฉียงปลายแหลม แกนขาวและเปลวพลังสีทองตามหลัง ไม่มีรอยฉีกแดงสามแนว ภาพใช้ built-in ImageGen; prompt ล่าสุดอยู่ที่ `output/rending_wave_icon/prompt_v2.json`.

## ชุด Runeblade / อาชีพขั้นถัดไป — 12 กันยายน 2026

ผู้ใช้ให้เปลี่ยนสีหลักให้เหมาะกับอาชีพ ชุดนี้ใช้ภาพวาดกรอบเหรียญเดิม แต่ Runeblade เป็นฟ้าอักขระ–กรมท่า–ทอง และอาชีพขั้นถัดไปเป็นม่วง–เงิน รูปทรงกลางสื่อแต่ละท่า แทนไอคอนเส้นและภาพ placeholder เดิม โดยไม่เปลี่ยนสกิลนักดาบ

ไฟล์ทั้ง 17 ภาพสร้างด้วย built-in ImageGen แล้วตัดเฉพาะพื้นนอกกรอบวงกลมด้วยโค้ดตามคำอนุมัติของผู้ใช้ “ใช้โค้ดตัดพื้นหลังเดิม” ภาพใช้งานเป็น **PNG RGBA 256×256 โปร่งใสจริง** พร้อมขอบ alpha ไล่ระดับและ mipmaps ภาพวาดภายในเหรียญคงเดิม ต้นฉบับก่อนตัดอยู่ `output/balance_v2/icons_original/`; ผลตรวจ alpha อยู่ `output/balance_v2/alpha_report.json`; ภาพเรนเดอร์จากเกมอยู่ `output/balance_v2/skill_icon_gallery.png`.

รายการภาพและ prompt ต้นฉบับ: `output/balance/icon_manifest.json`. `_tools/install_balance_icons.py` เป็นตัวติดตั้งเก่าและป้องกันการเขียนทับภาพโปร่งใสแล้ว อย่ารันตัวสร้างแพตช์ V2 ซ้ำ เพราะเป็นสคริปต์ย้ายข้อมูลครั้งเดียว ไม่ใช่ระบบ build.

UI ต้องซ่อนทั้งชื่ออาชีพขั้นถัดไปและรายการไอคอน/สกิลจนเปลี่ยนอาชีพสำเร็จ แสดงแท็บ `???` ก่อนนั้น
