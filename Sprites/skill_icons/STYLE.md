# รูปลักษณ์ไอคอนสกิลโจมตี

ใช้ภาพที่ผู้ใช้กำหนดเป็นต้นแบบหลัก: `Sprites/Magnum Break.png`, `Sprites/skill_slash.png`, `Sprites/Skill_bash.png`.

- กรอบวงกลมโลหะสีเทาอมบรอนซ์ ขอบลาดมีไฮไลต์บาง และวงในสีดำ
- ภายในสีแดงเข้มถึงดำ แสงโจมตีส้มทองและแกนแสงขาวร้อน ประกายแดง
- ลายเส้นภาพวาดแฟนตาซีแบบอนิเมะ คมชัด รูปทรงหลักอ่านออกเมื่อย่อเหลือ 48–64 px
- ไม่มีชื่อสกิล ตัวอักษร หรือตัวเลขในภาพ พื้นนอกกรอบโปร่งใสจริง
- รูปกลางสื่อพฤติกรรมสกิลและต้องแยกจากสกิลอื่นได้
- ไฟล์ใช้ในเกม PNG RGBA 256×256; เก็บต้นฉบับขนาดใหญ่ใน output

Rending Wave: อ้างอิงเอฟเฟกต์จริงจาก `Sprites/effects/rending_wave_gold.png` ที่ผูกผ่าน `data/sprites/fx_rending_wave.tres` เป็นลิ่มคลื่นเฉียงปลายแหลม แกนขาวและเปลวพลังสีทองตามหลัง ไม่มีรอยฉีกแดงสามแนว ภาพใช้ built-in ImageGen; prompt ล่าสุดอยู่ที่ `output/rending_wave_icon/prompt_v2.json`.
