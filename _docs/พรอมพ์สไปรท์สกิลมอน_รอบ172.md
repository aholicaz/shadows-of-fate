## วิธีใช้พรอมพ์ + สเปกภาพ

แต่ละตัวมีพรอมพ์อังกฤษ 1 ก้อน คัดลอกไปใช้กับตัวสร้างภาพได้เลย (ChatGPT Image / Midjourney / Leonardo) ท้ายพรอมพ์มีสเปกแผ่นสไปรท์และสไตล์ภาพรวมให้แล้ว

1. ถ้าตัวสร้างภาพทำแผ่นเรียงหลายเฟรมไม่ตรง ให้สั่งทีละเฟรม โดยเติมคำว่า `frame 3 of 8: full strength` แล้วต่อเฟรมเองด้วยโปรแกรมรวมชีท
2. พื้นหลังต้องโปร่งใส ถ้าได้พื้นดำมา ใช้โหมด Add/Screen หรือลบพื้นก่อนใส่เกม
3. ส่งภาพที่ได้มาให้ Claude ต่อเข้าเกม หรือใส่เองในช่องที่ระบุ แล้วตั้งความสูงตาม «ขนาดในเกม» (คิดไว้ให้เอฟเฟกต์เต็มช่องราว 90%)
4. ระบบที่เขียนว่า «ต้องต่อช่องเพิ่ม» (ทุบพื้น · เสาบอส) ตอนนี้เกมวาดเอง ส่งภาพมาแล้ว Claude จะต่อช่องใส่ภาพให้ในรอบถัดไป
