# บท 7 — มุสเปลเฮม: ไฟที่เผาคำสั่ง

งานต่อจากบท 6 ตามคำขอผู้เล่น 14 กันยายน 2026 หอ 100 ชั้นอยู่บท 8 ไม่ใช่บทนี้

## เส้นเรื่องและพื้นที่

โอดินเหลือเพียงเสียง «ลูกข้า—» ชื่อของคนแปลกหน้ายังไม่ถูกเปิดเผย ผู้เล่นนำเศษบัลลังก์ไปหาช่างผู้ลี้ภัยในมุสเปลเฮม ที่นี่ไฟเผาตัวอักษรได้ แต่คำสั่งของผู้ถือค้อนยังติดอยู่ในเหล็ก ผู้เล่นต้องเรียนรู้การตัดพันธะโดยไม่ลบตัวตนของผู้ถูกผูก

1. `cinder_crossing` ทางข้ามเถ้า — รอยต่อจากบัลลังก์ว่าง หมอกเย็นปะทะลมร้อน
2. `emberhaven` เมืองอัมเบอร์เฮเวน — ชุมชนผู้ลี้ภัย อาคารช่าง ร้านค้า หอจดหมายเหตุ และสถานพยาบาลต่างรูปลักษณ์
3. `chain_quarry` เหมืองโซ่คำสั่ง — เก็บหลักฐานจากสิ่งมีชีวิตที่ถูกตราค้อนควบคุม
4. `unwritten_forge` เตาหลอมไร้คำสั่ง — พิธี Runeblade → Ninth Edge; เผาพันธะ ไม่เผาชื่อ
5. `ash_procession` ทางขบวนเถ้า — ทดลองพลังใหม่ ปลดทหารที่เดินตามคำสั่งสุดท้าย
6. `oathbreak_crucible` เบ้าหลอมคำสาบาน — ผู้คุมเบ้าหลอมและทะเบียนส่งผู้คนขึ้นหอ 100 ชั้น ปิดบทด้วยการปูทางบท 8 โดยยังไม่มีประตูไปฉากที่ไม่มีอยู่

## ข้อกำหนด

- เควสต่อเนื่องหลัง `chapter6_done` ไม่เปิดเผยตัวคนแปลกหน้าก่อนเวลา
- ย้ายรางวัลเปลี่ยนอาชีพจาก RB13 มาที่บท 7; เซฟที่เป็น Ninth Edge แล้วไม่ถูกลดอาชีพ ไม่แจกแต้มซ้ำ
- เก็บ ID สกิล Ninth Edge ทั้งหก ปรับกลไก คำอธิบาย ภาพ และข้อกำหนดพร้อมกัน
- หลังเปลี่ยนอาชีพปลดเพดาน Base และสเตตัส ใช้ต้นทุนที่เพิ่มตามระดับ และคงเพดานความเร็วโจมตี/ลดคูลดาวน์เพื่อให้ต่อสู้ได้อ่านรู้เรื่อง
- เควสหลักไม่วนรับรางวัล; ทางกลับและจุดฟื้นชีพต้องใช้งานได้
- พื้นต่อเนื่องและฉากริมทางเป็นชิ้นเดียว; แบ่งฉากหลัง parallax; ไม่วางสิ่งกีดขวางกลางถนน
- NPC มองกล้อง สูงใกล้เคียงผู้เล่น; มอนยืนเดี่ยวหันซ้าย ต้นฉบับ 1000+ และเว้นขอบรวมประมาณ 30%; ไอเทมโปร่งใส 256
- ทดสอบโครงข่ายแมพ เควส การเปลี่ยนอาชีพ เซฟเดิม เพดานใหม่ ค่ารูนต่อการร่าย และภาพจริงทุกแมพ

สถานะ: เชื่อมข้อมูล ฉาก ภาพ และระบบบท 7 แล้ว ทดสอบเฉพาะส่วนที่เปลี่ยนและตรวจภาพจากตัวเกมจริง

## วิธีเล่นและระบบอาชีพ

จบ `chapter6_done` แล้วออกทางขวาของ `odin_seat` ไปทางข้ามเถ้า เควสเริ่มกับสวาลาในเมืองอัมเบอร์เฮเวน ที่ Base 96 ขึ้นไป บรินยาย้ายจากเมืองไปด้านทางเข้าเตาหลอมหลัง C7-3 ล้มผู้เฝ้าทั่ง อ่านทั่ง แล้วส่ง C7-4 กับบรินยาในแมพ `unwritten_forge` เพื่อเปลี่ยนเป็น Ninth Edge ได้ดาบไร้พันธะและ Job EXP สำหรับเริ่มเรียนสกิล

Base/Job/สเตตัสเติบโตต่อได้หลังเป็น Ninth Edge ใช้ขอบเขต integer เป็นตัวกันข้อมูลล้น ไม่ใช้เพดาน 150 ใหม่ ต้นทุน EXP และแต้มสเตตัสยังเพิ่มตามระดับ เพดานอัตราโจมตีและลดคูลดาวน์เดิมยังอยู่ เซฟเก่าที่เป็น Ninth Edge แล้วทำพิธีบท 7 ได้โดยไม่เริ่ม Job ใหม่หรือคืนแต้มซ้ำ

| สกิล | การทำงานที่ระดับ 1–5 |
| --- | --- |
| กายาไร้พันธะ | HP 4–20%, SP 3–15%; ความจุรูน 4 และเพิ่มเป็น 5 ที่ระดับ 5 |
| คมยืนยันนาม | คริ 2–10 จุด เจาะ DEF 4–20%; basic 3 จังหวะสร้างตรานาม 8 วินาที คมตัดพันธะใช้ตราเพิ่มดาเมจ 8–40% |
| อ่านรอยพันธะ | โบนัสกายภาพเพิ่มตาม DEF ของเป้าหมายอย่างต่อเนื่อง สูงสุด 4–20% |
| เงานามร่วมคม | ใช้ 2 รูน อยู่ 8 วินาที เงา 60–100% ATK ไม่คริ หนึ่งครั้งต่อเป้าหมายต่อการร่าย ไม่สร้างเงาซ้ำซ้อน; CD 18 / SP 36 |
| คมตัดพันธะ | ใช้ 3 รูน 1000–1600% ATK ไม่คริ เตรียม 0.3 วินาที ระยะ 560 สูงสุด 8 ตัว เปิดแผลกายภาพ +15% นาน 5 วินาที; CD 14 / SP 48 |
| ประกาศนามที่เก้า | ใช้ 4 รูน วงคงตำแหน่ง 5 วินาที อยู่ในวงเพิ่มคริ 20–40 จุด เป้าหมายในวงถูกเจาะ DEF เพิ่ม 25%; จบด้วย 1400–2200% ATK ไม่คริ; CD 45 / SP 72 |

สวาลามีคำแนะนำและบริการคืนแต้ม Ninth Edge ฟรีครั้งแรก หลังจากนั้น 10,000 z คืนเฉพาะสกิลอาชีพนี้ ไม่กระทบแต้ม/สกิลอาชีพก่อนหน้า ID ทั้งหกและภาพไอคอนเดิมยังใช้ได้ เอฟเฟกต์คมและวงใหม่เป็นสีม่วงเงิน

## เนื้อหาและภาพ

- 6 แมพ, 8 เควส, NPC ใหม่ 4 คนและศิลาพักนาม, มอน 7 ชนิดรวมมินิบอสและบอส
- ไอเทมใหม่ 11 ชิ้นและการ์ด 7 ใบ ภาพใช้งาน 256×256 RGBA; การ์ดต้นฉบับ 640×960 เก็บกรอบการ์ดเดิม
- มอนต้นฉบับอยู่ `Sprites/monsters/chapter7/source/`: canvas 1792×1792 ตัวมอนยังมีรายละเอียดมากกว่า 1000 px และเว้นขอบอย่างน้อย 15% ต่อด้าน รุ่นใช้งาน 1024; เป็นภาพยืนเดี่ยวสำหรับทำ sprite ต่อ ไม่ใช่อนิเมชันหลายท่า
- NPC มีการหายใจเบา ๆ ด้วยโค้ดรอบตำแหน่งเท้า; อยู่ริมทางและหน้าร้าน ไม่ใช่สิ่งกีดขวาง
- ถนนและขอบฉากประกอบต่อเนื่อง พื้นชนที่ y=880 ทุกแมพ เมืองกว้าง 6200, สนาม 4200; วงเตือนบอสคงอยู่ในพิกัดโลกก่อนดาเมจ 1.35 วินาที
- ไฟ/แสงในภาพเป็นส่วนของอาคารและพื้น เถ้าเรืองแสง 24–36 จุดต่อแมพ หมอกบาง และฉากหลัง parallax; เพลงใช้ไฟล์ที่มีในโครงการตามบรรยากาศ ไม่ได้สร้างเพลงใหม่
- บทจบให้เศษเส้นทางหอร้อยชั้นเพื่อปูบท 8 ไม่มีประตูไปฉากบท 8 ที่ยังไม่มี

## บาลานซ์และการตรวจ

เทียบบอสบท 6 `chained_garm` (180k HP / DEF 140): ลดผู้เฝ้าทั่งจากร่างแรกเหลือ 165k / DEF 165 เพื่อให้ผ่านได้ก่อนเปลี่ยนอาชีพ บอสบท 7 ใช้ 320k / DEF 195, ATK สูงสุด 1850 พร้อมวงเตือนที่หลบได้ ตัวเลขการสุ่มดาเมจจากสูตรจริง 1000 ครั้งต่อคู่เก็บใน `output/chapter7/balance.json` เป็นการเทียบตัวเลข ไม่ใช่เวลาเคลียร์จากการเล่นเต็ม rotation หรือการยืนยันว่าบาลานซ์สมบูรณ์ทุก build

- ระบบเควส/เซฟ/เติบโต/คืนแต้ม: `verify_final.log` 74 checks ผ่าน
- ทางวาป พื้น NPC ระยะอ่านหลักฐาน และการโจมตีบอส: `integration_final.log` 92 checks ผ่าน
- Ninth Edge การใช้รูน เงา ตรานาม และเข้าออกวง: `combat_final.log` 8 checks ผ่าน
- Runeblade เดิม: `runeblade_regression.log` 52 checks ผ่าน
- ภาพ runtime ทุกแมพ, เมืองสามย่าน, และภาพจอกว้าง อยู่ `output/chapter7/`; ไอเทม 18 ภาพผ่านการตรวจ alpha และขนาด มอน 7 ตัวผ่านการตรวจขอบและความละเอียด (`asset_audit.json`)
- Texture ฉากใช้ BC7 พร้อม mipmaps ประมาณ 18–22 MiB ต่อแมพตามจำนวนพิกเซล เฉพาะ texture ฉาก ไม่รวมตัวละคร UI หรือหน่วยความจำทั้งเกม ไม่ได้อ้างเป็นค่าที่วัดจาก GPU

การทดสอบทั้งหมดเริ่ม PlayerState ในหน่วยความจำและปิดเซสชัน autosave ไม่แก้เซฟจริง ไม่ได้ commit หรือ push
