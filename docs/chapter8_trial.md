# บท 8 — อิกดราซิล: ตัวอย่างชั้น 1–20

> เอกสารประวัติช่วงทดลอง 20 ชั้น ขอบเขตปัจจุบัน 50 ชั้นและงานภาพที่เชื่อมต่อแล้วดู `chapter8_tower50.md` รายละเอียดรางวัล/เวฟด้านล่างบางส่วนเป็นของเวอร์ชันเก่า

## ขอบเขตที่เล่นได้

- ทางเข้าจากอัมเบอร์เฮเวน x=1850 หลังส่ง C7-8 (`chapter7_done`)
- จุดพักรากพร้อมสวาลาและเควสต่อเนื่อง 4 เควส; Ninth Edge ยังคงเป็น Class 3 ไม่มีอาชีพถัดไป
- 20 ชั้นแยกฉาก โหลดเฉพาะฉากและศัตรูที่ใช้ ไม่สร้างหอสูง 20 ชั้นในฉากเดียว
- ทุกชั้น: มอนเก่า 3 ตัว (ชั้น 11+ เป็น 4 ตัว) → พัก 2.5 วินาที → บอสเก่า
- ชั้น 5/10/15/20: หลังบอสเก่ามีผู้คุมใหม่อีกหนึ่งตัว รวมบอส 24 encounters ใน 20 ชั้น
- ประตูทางขึ้นต้องเคลียร์การต่อสู้ในการเข้ารอบนั้น; ออกจากหอได้ตลอด
- บันทึกชั้นที่ผ่านด้วย story flags เดิมของเกม; จุดพักกลับขึ้นชั้น 6/11/16 เปิดเมื่อผ่าน 5/10/15
- ผ่านทุก 5 ชั้นฟื้น HP/SP; กลับจุดพักรากฟื้นได้เช่นกัน
- รางวัล EXP/Job EXP/เงินจ่ายเมื่อเคลียร์ชั้นครั้งแรกเท่านั้น; ศัตรูหอไม่ดรอปของบทเก่าหรือจ่าย EXP แยก
- ชั้น 20 ตั้ง `c8_trial20_done` เท่านั้น **ไม่ตั้ง `chapter8_done`** และไม่สร้างประตูชั้น 21/บท 9 ที่ยังไม่มี

## ฉากและเรื่อง

ตัวอย่างนี้ใช้ภาพ parallax และพื้น organic เดิม 4 ชุด: ทางสายราก, โถงน้ำแข็ง, สวนผลึก, ทางขบวนเถ้า เพื่อทดสอบ encounter ก่อนผลิตภาพหอเฉพาะทาง ภาพในช่วงละ 5 ชั้นใช้ชุดเดียวกัน ไม่ใช่ภาพใหม่ 20 ภาพ

รากอิกดราซิลสร้างผู้เฝ้าจากความทรงจำการต่อสู้ ส่วนรายชื่อผู้ติดค้างเป็นคนจริง สวาลาให้ผู้เล่นเปิดเส้นทางโดยไม่ทำลายรากที่เลี้ยงคนเหล่านั้น เควสใช้ธงชั้นที่ผ่าน จึงย้อนหลังได้หากปีนก่อนรับเควส ไม่มีการเปลี่ยนคลาสซ้ำ

## บาลานซ์ตั้งต้น

`chapter8_tower_data.gd` สำเนา MonsterData ก่อนปรับ ใช้ ID เฉพาะชั้น จึงไม่แก้พลัง ดรอป quest kill หรือ respawn lock ของมอนต้นฉบับในบท 1–7 ใช้แอนิเมชันเดิมร่วมกันโดยไม่แก้ทรัพยากรภาพ

ให้ s = ชั้น − 1:

- เลเวล = 110 + ชั้น
- HP มอน = 34,000 × (1 + .052s); บอสเก่า = 200,000 × (1 + .052s); ผู้คุม = 285,000 × (1 + .052s)
- ATK สูงสุดมอน = 1,350 × (1 + .027s); บอส = 1,950 × (1 + .027s); ATK ต่ำสุด = 88%
- DEF มอน = 135 + 2.5s; บอส = 170 + 2.5s; ไม่เพิ่ม DEF แบบทวีคูณจนทุกตัวอึดเกินไป
- มอนชั้น 1→20: HP 34,000→67,592, ATK max 1,350→2,042
- บอสเก่าชั้น 1→20: HP 200,000→397,600, ATK max 1,950→2,950
- ผู้คุมชั้น 5/10/15/20: HP 344,280 / 418,380 / 492,480 / 566,580

ตัวอย่างดาเมจตามสูตรปัจจุบัน `Combat.monster_skill_hits_player`: สมมติ HP 6,000, DEF 300, ไม่รวมการหลบเชิงตำแหน่ง สกิลผู้คุมชั้น 20 multiplier 2.7 ทำประมาณ 1,542–2,230 ต่อครั้ง (ATK roll 2,596–2,950 × 2.7 × 100/400 × variance .88–1.12) จึงอันตรายเมื่อพลาดต่อเนื่อง แต่ไม่ใช่สุ่มคริทะลุเกราะตายครั้งเดียว นี่เป็นประมาณการตามสูตร ไม่ใช่เวลาเคลียร์หรือหลักฐานว่าความยากสมดุลสำหรับทุก build

ยังต้องเล่นจริงด้วยอุปกรณ์/สกิลของเซฟผู้ใช้เพื่อปรับ HP, เวลาต่อชั้น และการใช้ยา ยังไม่ได้สรุปว่าจบ 20 ชั้นด้วย build ปกติได้สมดุลแล้ว
