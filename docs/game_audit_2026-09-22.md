# ตรวจเกม 22 กันยายน 2026 — รายงานก่อนแก้

ขอบเขต: ตรวจซอร์สในเครื่อง ทดสอบ Godot 4.7.2 แบบ headless และ OpenGL preview 1280×720 ไม่ได้เล่นเนื้อเรื่องครบทุกบท ไม่ได้ทดสอบบน Samsung จริงหรือเว็บไซต์ที่เผยแพร่ ไม่แก้ระบบเกมหรือเซฟผู้เล่นในรอบนี้

## ควรแก้ก่อน

1. **P1 แจกของเควสซ้ำเมื่อกระเป๋าเกือบเต็ม — ทำซ้ำได้จริง**
   - `scripts/core/player_state.gd:184`: inventory.add ทำงานก่อนยืนยันส่งเควส หากเพิ่มได้บางส่วนจะ return false โดยไม่คืนของ
   - `scripts/core/inventory.gd:81`: add อนุญาตเพิ่มบางส่วนแล้วคืนจำนวนที่เหลือ
   - ทดสอบ hans_poring ซึ่งแจก phracon 3 ชิ้น กระเป๋าหนึ่งช่องมี 98/99: ส่งไม่สำเร็จแต่กลายเป็น 99/99 และเควสยังพร้อมส่ง เอาออกหนึ่งชิ้นแล้วทำซ้ำได้
   - แก้ด้วยตรวจความจุครบทั้งรางวัลก่อนเปลี่ยนข้อมูล หรือทำธุรกรรมที่คืนสถานะครบเมื่อส่งล้มเหลว พิจารณาช่องที่จะว่างหลังหักของเควสด้วย
   - หลักฐาน: output/game_audit/reproduce.log

2. **P1 หน้าแผนที่และ GM ยังโหลดภาพมอนเพื่ออ่านข้อมูล — ยืนยันเส้นทางโค้ด**
   - `scripts/ui/world_map_page.gd:352` โหลด MonsterData ทั้งชุดแม้แสดงเพียงชื่อ/เลเวล/ของดรอป
   - `scripts/ui/gm_window.gd:147` load_all_monsters สำหรับรายชื่อ ทำให้โหลดทุกมอน รวมทรัพยากรภาพ
   - ใช้ get_monster_info สำหรับรายการ แยกการโหลด actor ไปตอนกดสร้างจริง ไม่จำเป็นต้องโหลดภาพตอนอ่านชื่อ
   - ยังไม่ได้วัดเวลาหน้าแผนที่บน S23 จึงไม่ยืนยันว่าเป็นสาเหตุเดียวของการรีโหลดเว็บ

3. **P1 ก่อนเผยแพร่: GM ไม่มี release guard — ยืนยันโค้ด**
   - scripts/core/input_setup.gd:28 ผูก F10; scripts/ui/ui_manager.gd:89 สร้าง GM และ :274 เปิดได้ ไม่มี OS.is_debug_build/สิทธิ์เทสคุมเส้นทางนี้
   - แยก developer build ออกจาก release และตรวจการเรียกตรงด้วย ไม่ใช่แค่ซ่อนปุ่ม
   - ขณะนี้ผู้พัฒนาต้องใช้ GM ทดสอบ จึงยังไม่ปิดเอง

4. **P2 Web export อาจพกงานทดสอบที่ไม่ใช่เกมจริง**
   - export_presets.cfg:9 all_resources; :11 ยังไม่ exclude output หรือ test scenes
   - output มีภาพ/เสียง/scene/resource 10,097 ไฟล์ รวมต้นฉบับ ~6,151.7 MiB; 129 ไฟล์มี .import รวมต้นฉบับ ~120.1 MiB
   - ตัวเลขนี้ไม่ใช่ขนาด PCK ที่ส่งจริง ต้องตรวจรายการ export/dependency ก่อนสรุปปริมาณส่วนเกิน
   - ย้ายไฟล์ที่เกมใช้งานจริงออกจากโฟลเดอร์ทดลองแล้ว exclude สิ่งที่ไม่จำเป็น ห้ามลบ/ตัด output ทั้งหมดโดยไม่ตรวจ references

   - ถ้าปรับเลเวล/ชื่อ/ดรอปแล้วลืม _tools/build_monster_quest_catalog.py เกมจริงกับใบล่านักล่าจะไม่ตรงกัน

6. **P2 บทพูดเควสมีจำนวนไม่ตรงเงื่อนไข — ยืนยันข้อมูล**

   - เปลี่ยนคำบรรยายให้ตรง 50 หรือใช้ตัวเลขจากเงื่อนไขเดียวกัน ลดโอกาสคลาดหลังปรับบาลานซ์

7. **P2 ชื่อสกิลยาวล้นการ์ดใน skill tree — เห็นในภาพทดสอบ**
   - output/mobile_ui/skill_window.png: ชื่อ Sword Mastery/Rending Wave ยาวเกินการ์ด
   - ใช้สองบรรทัดหรือ ellipsis พร้อมชื่อเต็มในแผงรายละเอียด ไม่ลดฟอนต์จนอ่านยาก
   - การกดปุ่ม สลับชุด และตำแหน่งช่อง 3/4 ผ่าน test ที่ 1280×720; ไม่ใช่การรับรองทุกอัตราส่วนจอ

## ประเด็นบาลานซ์ ไม่ใช่บัคที่ยืนยัน

8. **Job EXP และรางวัลหอยังอาจทำให้โตเร็วหลังลด Base EXP เควส**
   - c7_4_ninth_edge ให้ Job EXP 280,000 หลังเปลี่ยนอาชีพ สูตรปัจจุบันคำนวณกรณีเริ่ม Job1/EXP0 ได้ประมาณ Job13 (12 แต้ม) ยังไม่รวมแต้ม/สกิลเริ่มต้น
   - ค่านี้คงไว้โดยตั้งใจในรอบลด Base EXP ต้องเลือกเป้าหมายอัตราได้แต้มสกิลก่อนลด
   - มอน cinder_hound/ash_knight ให้ Base EXP ประมาณ 1.11%/1.25% ที่เลเวลเท่ามอน และ floor-clear หอมีรางวัลแยกจากเควส จึงยังเป็นแหล่งเลเวลขึ้นไว
   - ควรทดสอบเส้นทางจริงก่อนเพิ่ม EXP ต่อเลเวลทั้งระบบ
