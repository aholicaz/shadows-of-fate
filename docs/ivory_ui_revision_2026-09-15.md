# Ivory UI correction — 2026-09-15

The previous colored gold/blue vector set did not follow the user's established visual language. The current set uses warm ivory silhouettes, dark engraved contours and restrained ornament on dark petrol backgrounds, matching the supplied historic UI mockup.

Assets: `Sprites/ui/ivory/menu_atlas.png`, generated by the built-in Imagegen tool using the user's mockup and swords as style references. Source is 1254×1254 RGBA with real alpha (0–255); no checkerboard removal or raster editing was performed. Individual AtlasTexture resources use optically fitted regions determined from alpha bounds. `output/mobile_ui/ivory_regions.json` records regions. The original transparent 512×512 swords.png supplied by the user was copied intact and used by attack.tres.

Runtime: UITheme prefers the ivory atlas resources for the six menu icons and swap icon. Attack uses the user's ivory crossed swords. Bank switching changes arrow orientation instead of blue tint and the tooltip names the current bank. Quest location labels now use ivory text with a restrained dark backing and a thin muted lower rule. Removed down button, floating minimap, full-map M input and eight saved skill slots are retained.

Verification: focused mobile_ui_test.tscn renders desktop/touch layouts against the project's actual dark_forest_2_depth.png backdrop (a composed test view, not an on-device playtest). It checks saved slot compatibility, bank switching, input/button layout and map opening. Preview: output/mobile_ui/mobile.png. Log: output/mobile_ui_ivory_test.log.

No deployment was performed. Prior colored SVGs are superseded by preferred ivory resources; they are not the displayed menu/attack/swap assets.
