# ตรวจ error, Git และขนาดภาพ — 13 กันยายน 2026

## สิ่งที่แก้แล้ว

- GitHub Desktop หยุดที่ขั้น **Commit** เพราะ `.git/index.lock` ว่างค้างตั้งแต่ 12 กันยายน 14:14 ตรวจไม่พบกระบวนการ `git` หรือ `git-lfs` ทำงานแล้วจึงลบเฉพาะล็อกนี้ ไม่มีการ reset, commit, push หรือเปลี่ยนประวัติ งานที่แก้ไว้ยังอยู่ครบ
- Godot อ่าน `_to_delete/npc_lines.csv` เป็น translation CSV แล้วใช้หัวคอลัมน์ `ไฟล์เสียง (Sprites/voice/...)` เป็นชื่อภาษา ทำให้สร้างเส้นทาง `.translation` ที่ใช้ไม่ได้ เพิ่ม `.gdignore` ใน `_to_delete` และ `output` พร้อมให้ Git เก็บเฉพาะ marker เหล่านี้
- Godot 4.7.2 นำเข้าโครงการจนจบ ไม่พบ `npc_lines`, parse error หรือ failed resource loading ในบันทึกรอบนี้ ยังมีข้อจำกัดสิทธิ์ของเครื่องทดสอบเกี่ยวกับ user directory, certificate store และการเขียน editor settings ใน Program Files จึงไม่อ้างว่า log ทั้งหมดไม่มี error
- ปิดขั้นตอน `webtrim.py 0.42 --apply` ใน GitHub Actions ตามคำสั่งให้คงรายละเอียดและตำแหน่งเฟรม ตัวปรับ import compression สำหรับเว็บยังอยู่ ไม่เปลี่ยนขนาดภาพต้นฉบับหรือพิกัดเฟรม การปิดการย่อจะทำให้เว็บใหญ่กว่า build ที่เคยย่อ ต้องวัด PCK ใหม่หลัง export; ตัวตรวจขนาดเว็บเดิมยังทำงาน
- ตรวจ SHA-256 พบไฟล์ใน `_to_delete` ที่มีสำเนาตรงกันทุกไบต์ภายนอก 24 ไฟล์ ลบแล้ว ประหยัด 27.07 MiB เก็บสำเนาภายนอกทั้งหมด รายการหลักฐานอยู่ `output/maintenance_2026-09-13/archive_duplicates.json`

ระบบตรวจอนุมัติอัตโนมัติไม่อนุมัติการล้าง `_to_delete` ทั้งหมด เพราะยังมีต้นฉบับและไฟล์สำรองที่ไม่ซ้ำ การไม่ถูกเรียกใช้โดยเกมไม่ได้พิสูจน์ว่าผู้ใช้ไม่ต้องการสำรองเหล่านั้น จึงเก็บส่วนที่ยังยืนยันไม่ได้ไว้
