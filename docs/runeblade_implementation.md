# Runeblade — อัศวินดาบรูน

สถานะ: ระบบเล่นได้สำหรับทดสอบบาลานซ์ในโปรเจกต์ สร้าง 11 กันยายน 2026

## เริ่มเล่น

หลังจบ C2-8 คุยกับ **บรอกก์** ที่เมืองนิดาเวลลีร์ เลือกเมนู **เส้นทาง Runeblade** แล้วนำเรื่องไปหา **ผู้อาวุโสญอร์ดา** ที่เมืองวานาเฮม บท 3 ผู้เล่นเดิมที่จบบท 2 แล้วกลับไปรับได้ ไม่ต้องเริ่มเซฟใหม่

แบ่งเรื่องเป็นสามช่วง โดยแยกเป้าหมายย่อยเพื่อให้ติดตามได้:

| ช่วง | เควส | สิ่งที่ผู้เล่นทำ |
|---|---|---|
| เสียงเรียก | R1 สิ่งที่ค้อนมิได้สอน / R2 อักขระที่ปฏิเสธนาย | รับเรื่องจากบรอกก์ พบญอร์ดา และอ่านศิลาข้างลานพิธี หลังผ่านประตูเมืองบท 3 |
| การพิสูจน์ | R3 เสียงจากใต้บึง / R4 คมและแรง | ตามสามเบาะแสในบึงหมอกเงิน แล้วฝึกคอมโบและการสวนกลับ หลังเควสหลัก C3-6 |
| คำสัตย์ | R5 ผู้กินคำสัตย์ / R6 Runeblade | เลเวล 50 เข้าดันลับ ปลดเสาสามต้น ชนะ Baphomet คืนอิสระให้แก่นรูน แล้วกลับทำพิธีและส่งเควสกับญอร์ดาในเมือง |

ลานทดสอบเข้าได้จากศิลาทางขวาของเมือง (x=2750) ขณะรับ R4: ทดสอบแรกลงคอมโบครบสามชุดโดยหลบเขตสีแดง ทดสอบที่สองเปิดแผลด้วย Rending Wave แล้วใช้ Bash ในช่วงวงสีทอง เตรียมเรียนและใส่สองสกิลนี้ไว้ก่อนเริ่มฝึก

## ดันลับ

**วิหารเขาทมิฬใต้ราก** อยู่ใต้ซุ้มรากปลายทางขวาของ **บึงหมอกเงิน** (x=3570) มีเบาะแสที่ x=1600, 2600, 3200 ชื่อทางเข้าจะเปิดเผยหลังส่ง R3 ต้องเลเวล 50 และผ่าน R4 จึงเข้าได้

Baphomet และ Baphomet Jr ถูกนำออกจาก dark_forest_2 บท 1 แล้ว ดันใหม่ใช้ธงชัยชนะเฉพาะ เพื่อไม่ให้ผู้เล่นที่เคยฆ่าบอสในบท 1 ข้ามเควสนี้

- เสาพันธนาการสามต้นมีผู้เฝ้า ฆ่าแล้วต้องกด F ปลดเสาก่อนผู้เฝ้ากลับมา
- จุดพักหน้าห้องบอสฟื้น HP/SP และใช้เป็นจุดกลับมาเมื่อตายในดัน
- Baphomet HP 65,000 มีสามช่วง: มากกว่า 70%, 35–70%, ต่ำกว่า 35% ช่วงท้ายฟันต่อเนื่องสองจังหวะ
- ลูกน้องที่เรียกมีสูงสุด 2 / 3 / 3 ตัวตามช่วง มีสัญญาณเตือนก่อนเกิด และเว้นช่วงพักหลังเคลียร์หมด
- ลูกน้องบางตัวร่ายเขตชะลอ โจมตีขัดการร่ายได้ ไม่ใช้การผลักถี่ ๆ ล็อกผู้เล่น
- ลูกน้องที่บอสเรียกไม่ให้ EXP, Job EXP, เงิน หรือไอเทม ผู้เฝ้าเสายังมีรางวัล
- ชัยชนะและเสาที่ปลดแล้วอยู่ในข้อมูลเซฟตามระบบบันทึกเดิม ชนะแล้วบอสไม่เกิดใหม่ในเซฟนั้น

## อาชีพและแต้ม

การเปลี่ยนอาชีพต้องส่ง R6 ในเมืองวานาเฮมที่เลเวล 50 ขึ้นไป เก็บสกิลเดิมและปุ่มลัดเดิมไว้ ได้แต้มรูนแยก 5 แต้ม และอีก 1 แต้มต่อ Base Level หลังเปลี่ยน จนรวมสูงสุด 30 แต้ม ไม่ใช้แต้มสกิลเดิม จึงเปลี่ยนช้ากว่าเลเวล 50 ได้โดยยังเริ่มที่ 5 แต้มเหมือนกัน

| กลุ่ม | สกิล | บทบาท |
|---|---|---|
| ร่วม | กายารูน / เกราะรูน | HP-SP และโล่ชั่วคราว |
| ตีไว-คริ | จังหวะคมดาบ → รูนคมสังหาร → Rune Flurry → Unbroken Edge | สะสมความเร็ว เพิ่มคริ ฟันหกครั้ง และดาบสะท้อนระหว่างบัฟ |
| สกิลหนัก | Tempered Might → Anvil Cleave → Faultline → Worldcleaver | เพิ่มพลังและเจาะ DEF ฟันหนักเป็นกลุ่ม มีเวลาง้าง ดาเมจสายนี้ไม่ติดคริ |

แต่ละสกิลมี 5 ระดับ ต้องเต็มสกิลก่อนหน้าเพื่อเลื่อนตามสาย อัลติเมตสองสายเรียนพร้อมกันไม่ได้ แต่ผสมสกิลขั้นต้นได้ เลือกคำตอบในพิธีเพื่อบันทึกความชอบได้โดยไม่ล็อกสายถาวร

รูนสะสมสูงสุด 3 หน่วยจากคอมโบจบชุดหรือสกิลโจมตีที่โดน จำกัดการเกิดรูนหนึ่งครั้งต่อวินาที ไม่ให้สกิลหลายฮิตปั๊มรูนเต็มทันที อัลติเมตใช้ 3 รูน เมื่อออกจากการต่อสู้นานรูนค่อย ๆ ลด

Worldcleaver ยกเลิกช่วงต้นการง้างด้วยปุ่มกระโดด/หลบได้โดยไม่เสีย SP หรือรูน และติดคูลดาวน์สั้น 2 วินาที หลังพ้นช่วงยกเลิกจึงจ่ายทรัพยากรและรับความเสียหายน้อยลง 20% ระหว่างท่า

ศิลาคำสัตย์ใกล้ญอร์ดา (x=740) คืนแต้ม Runeblade ฟรีครั้งแรก หลังจากนั้น 10,000 z ไม่ล้างสกิลนักดาบเดิม

## ร่องรอยอาชีพขั้นถัดไป

R7 อักขระที่เก้าให้อ่านศิลาหลังเปลี่ยนอาชีพ เชื่อมกับรูนเก้าดวงใต้บัลลังก์ Baphomet และเสียงจากแดนเหนือ เมื่อถึงเลเวล 90 มีข้อความเตือนและธง rb_next_job_ready สำหรับเนื้อหาต่อไป ยังไม่เปิดอาชีพหรือเควสที่ทำไม่จบ สามารถปรับเลเวลและกำหนดชื่อขั้นถัดไปภายหลังได้

## งานภาพและการตรวจสอบ

มีไอคอนสกิลใหม่และเอฟเฟกต์รูนระหว่างต่อสู้ ปัจจุบันใช้ท่าเคลื่อนไหวของตัวละครเดิม และนำฉากโรงตีเหล็ก/เมืองที่มีอยู่มาจัดเป็นดันและลานฝึก ยังไม่ได้เพิ่มชุดอาชีพเป็น sprite animation หรือฉากวาดใหม่เฉพาะพื้นที่ บาลานซ์ต้องเก็บผลจากการเล่นจริงต่อ

- runeblade_test.tscn: ผ่าน 49 ข้อ รวมการเก็บ/โหลดสถานะ เควส แต้มรูน สกิล ลานฝึก และชัยชนะบอส
- rending_wave_test.tscn: ผ่าน 41 ข้อ หลังเชื่อมระบบโจมตีใหม่
- ตรวจภาพจริงจาก runeblade_preview.tscn: บอสและตัวละครอยู่บนพื้นตรงกัน พร้อมเขตเตือนโจมตี
- ฉากทดสอบใช้ข้อมูลผู้เล่นในหน่วยความจำ ไม่เขียนทับเซฟจริง
- ยังมีข้อความทรัพยากรเดิมหายบางรายการ (Jellopy และการ์ด Poring) และคำเตือนทรัพยากรค้างตอนปิดฉากทดสอบ ไม่ใช่ผลการทดสอบสกิลล้มเหลว
