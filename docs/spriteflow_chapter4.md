Run ใช้ Walk และ Skill ใช้ภาพ Attack ตามระบบเดิม คงค่าพลัง ขนาดตัว กล่องชน จังหวะสร้างความเสียหาย จำนวนครั้งที่ทำความเสียหาย และข้อมูลดรอปเดิมไว้ ภาพชุดที่มีสองครั้งยังเล่นครบ แต่ไม่ได้เพิ่มจำนวนดาเมจจากคำบรรยายที่ฝังอยู่ในชุดภาพ

ภาพเต็มโปร่งใสถูกวางบน AtlasTexture พร้อม margin เป็นผ้าใบ 1600×1400 จุดเท้า (800,1100) ใช้ตำแหน่งคงที่ต่อชุดและสเกลชดเชยจากท่าเริ่มต้น ไม่จัดกลางใหม่ทุกเฟรม

## เปิดดู
