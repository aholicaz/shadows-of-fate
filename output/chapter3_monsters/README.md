# มอนสเตอร์บทที่ 3 — Shadows of Fate

อิงทรัพยากรมอน ไอเทมดรอป เควส C3-8/C3-10 และภาพแมพในโปรเจกต์ ใช้รูปมอนที่มีอยู่ในภาพ gameplay เป็นแนวทางสไตล์

สร้างด้วย **built-in ImageGen** แบบแยกไฟล์ แล้วแก้ทิศทางและลบพื้นหลังด้วยเครื่องมือเดิม ยกเว้นราชินีหนามที่เครื่องมือยังให้พื้นลายตารางหลังลองหลายครั้ง ผู้ใช้อนุญาตให้ตัดพื้นหลังด้วยสคริปต์แล้ว จึงใช้ `cutout_thorn.ps1` (PowerShell/C#) ตัดเฉพาะลายพื้นและรักษาดอกไม้สีงาช้าง ชุด prompt อยู่ใน `prompts.json` และคำสั่งแก้รอบเพิ่มเติมใน `alpha_retries.json` ตรวจข้อมูล Alpha ครบ 9 ไฟล์ด้วย `check_alpha.ps1`; ผลอยู่ใน `alpha_report.json`

ชุดนี้เป็นภาพต้นแบบหนึ่งท่าต่อตัว ยังไม่ใช่ชุดแอนิเมชัน Idle/Run/Attack/Death และยังไม่เปลี่ยน SpriteFrames หรือไฟล์ placeholder ที่เกมใช้อยู่ เพื่อรักษาทรัพยากรเดิมขณะเลือกแบบสำหรับทำแอนิเมชัน
