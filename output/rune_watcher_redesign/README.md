# Rune Watcher — redesign concept

User preference (2026-09-10): all future isolated monster designs must have a genuinely transparent PNG background. Verify alpha before calling an asset transparent; a painted checkerboard is not acceptable.

Version 3 explores an upright arch-headed basalt automaton, asymmetric seal-stamp fist and articulated hand with a floating rune tablet. Generation prompt: prompt_v3.txt; transparency edit prompt: background_prompt_v3.txt. Generated through the built-in image_gen tool.

Final V3: rune_watcher_v3_transparent.png, 1254 x 1254 RGBA. Verified alpha by sampling every four pixels: 54,592 fully transparent samples; corner alpha 0. The initial rune_watcher_v3.png is an intermediate with a baked checkerboard, not the final deliverable. Existing gameplay assets remain unchanged.

A short engraving scepter supports its existing rune-explosion ability. Compact grounded silhouette sized for the current 330px display height.
