# Petrol UI Kit — Godot 4.x

ชุดเริ่มต้น ไม่ใช่ระบบเกมสำเร็จรูป ไอคอน SVG 8 เมนูไม่มีพื้นหลัง ไม่มีลายตาราง ตัวอักษรใช้ Label ของ Godot เพื่อเปลี่ยนภาษาและขนาดได้

## เปิดตัวอย่าง

1. แตก ZIP ในโฟลเดอร์ใหม่ อย่าทับเกมเดิม
2. Godot 4 > Import > เลือก project.godot > Run
3. คลิกเมนูเพื่อเปิดหน้าต่าง กด Esc เพื่อปิด

## ใช้ในเกมหลัก

- ไฟล์ icons/*.svg คือภาพเมนู นำเข้า Godot ได้โดยตรง
- components/*.svg คือกรอบช่องไอเทม ปุ่มวงกลม และปุ่มปิด
- ไม่ใส่ข้อความลงภาพ ให้ใช้ TextureRect และ Label แยกกัน
- petrol_ui.gd สร้างธีม StyleBoxFlat และ UI ตัวอย่าง หากย้ายโฟลเดอร์ในเกมต้องแก้ res://icons/ ให้ตรงตำแหน่งใหม่
- เชื่อม signal menu_requested(menu_id) กับระบบจริง
- Equip/Compare ถูกปิดไว้โดยตั้งใจ ยังไม่มีระบบสวมใส่จริง
- หน้าอื่นนอกจาก Inventory/Equipment เป็นจุดเชื่อมต่อ ยังไม่ใช่หน้าที่ทำเสร็จ
- ค่าพลัง รายการไอเทม ชื่อ และเควสต์เป็นข้อมูลตัวอย่าง
- เดโมใช้ 1280×720 แนวนอน ยังต้องทดสอบสเกลในความละเอียดเป้าหมาย ไม่ได้อ้างว่ารองรับมือถือทุกจอ
- Godot 3 ต้องปรับสคริปต์ก่อนใช้

## รูปแบบ

พื้น #102725, ข้อความ #ECE7D8, ข้อความรอง #81958A, สีเน้น #B5A16C
ใช้กรอบ 1 px, มุม 4 px, ช่องว่าง 8/12/24 px, ไอคอนเมนู 32 px, ตัวอักษร 12–22 px ในเดโม
ไฟล์ SVG เป็นภาพเวกเตอร์ที่เขียนตรงสำหรับ UI เรียบ ไม่ใช้ภาพสร้าง AI เป็นไฟล์ผลิตจริงในชุดนี้

## สถานะการตรวจ

ตรวจโครงสร้าง SVG ได้ แต่ต้องเปิดเดโมใน Godot เพื่อตรวจหน้าตาและพฤติกรรมจริงก่อนนำขึ้นเกม
